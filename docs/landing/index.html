MeetingGenie

Your prepared talking points, waiting at the notch when a meeting starts. Written by your AI agent, glanceable mid-call.

Install

brew install --cask fontesgerards/meetinggenie-tap/meetinggenie

Signed & notarized. Installs the menu-bar app and the notch CLI. Updates itself in the background.

How it works

  • Your agent writes the points. Any shell-capable agent runs the notch CLI to set talking points for a time.
  • They appear at the notch. At the meeting's start time, a calm peek shows them at the MacBook notch.
  • Only times + notes are stored — no calendar, no attendees, no integrations, no tracking.

For agents

Once installed, the CLI describes itself:

notch skill        # prints the agent skill (SKILL.md)
notch add 2pm --title "Q3 Sync" "Raise the budget" "Ask about timeline"
Source & the portable skill on GitHub. No analytics on this page.
